## Безпека застосунку

### 1. Захист від XSS
* **Знайдена вразливість:** Під час додавання нового міста користувачем у формі поле `name` вставлялося безпосередньо в DOM через `innerHTML` без фільтрації спеціальних символів. Введення пейлоаду `<img src=x onerror="alert('XSS')">` призводило до несанкціонованого виконання довільного JavaScript-коду.
* **Спосіб виправлення:** Реалізовано функцію `escapeHtml()`, яка санітизує вхідні рядки (`&`, `<`, `>`, `"`, `'`) перед підстановкою в HTML-шаблони. Крім того, для оновлення динамічних значень температури та описів використовується безпечна властивість `textContent`.

### 2. Аудит локальних сховищ
* Усі дані в сховищах `WeatherDB` та `localStorage` обмежені виключно координатами, назвами міст та метеопоказниками.
* Чутлива інформація (токени автентифікації, персональні дані користувачів, паролі) у клієнтських сховищах не зберігається.

### 3. HTTPS та робота з API
* Усі виклики до зовнішнього сервісу Open-Meteo та підключення бібліотеки Vue 3 здійснюються за протоколом HTTPS.
* Код не містить захардкоджених секретів або приватних API-ключів.
